# CZI 図作成ツール

Zeiss の `.czi` 顕微鏡画像から、論文・発表用の「1 パネル画像」を **PNG** または **PowerPoint（.pptx）** で作ります。

- 上：抗体名を**その色で**並べたタイトル枠（例「Hoechst / MAP2 / TBR1」）
- 左：自由に書ける**縦書きラベル枠**（例「Glu DIV 30」）
- 右下：**スケールバー**（.czi に記録された µm/px から正確に長さを計算）
- 必要なら、各チャンネルを**グレーの単色パネル**としても書き出せます

細胞数や陽性率などの**定量はしません**（それは `run_analysis_9th.py` の役目です）。
画像の数値も変えません。変えるのは「どの明るさを白／黒として見せるか（表示レンジ）」だけです。

---

## 1. ファイル構成

| ファイル | 役割 |
|---|---|
| `launch_gui.bat` | **ダブルクリックで起動**するためのファイル |
| `czi_figure_gui.py` | 画面 |
| `czi_figure_core.py` | 描画エンジン。画面なしでもコマンドで使えます |
| `run_analysis_9th.py` | .czi を読む部分だけを借りています。**1 文字も変えていません** |
| `czi_summary.py` / `czi_summary_gui.py` | pptx データまとめ（7 パネル × 2 枚）のエンジンと画面 |
| `templates/summary_template.pptx` | pptx データまとめの様式（参考 pptx から見本画像を抜いたもの） |

これらは**同じフォルダ**に置いてください（`templates` フォルダごと）。

## 2. 起動

1. `launch_gui.bat` をダブルクリックします。
   - 解析用の conda 環境（cellcount）で使うときは、`launch_gui.bat` をメモ帳で開きます。
     `rem call conda activate cellcount` の先頭にある `rem ` を消して保存してください。
2. 「CZI 図作成」の画面が開きます。左が設定、右がプレビューです。

## 3. 基本の使い方（1 枚つくる）

### ① 開く
「.czi を開く…」を押します（`Ctrl+O`）。`.czi` を画面にドラッグしても開けます。

抗体名と左ラベルは、**ファイル名から自動で推測**して入ります。
たとえば `[glu day30]TBR1 rabbit647, MAP2 chicken488.czi` なら、次のようになります。
- 647 のチャンネル → TBR1
- 488 のチャンネル → MAP2
- 左ラベル → glu day30

推測が違っていたら、その欄を書き直してください。

### ② チャンネル（表の 1 行＝1 チャンネル）
| 列 | 意味 |
|---|---|
| ▲▼ | タイトルでの並び順を変えます |
| ON | 合成画像とタイトルに入れるかどうか |
| 表示名 | タイトルに出す抗体名 |
| 色 | 青・緑・赤・オレンジ・マゼンタ・シアン・黄・白から選びます（どのチャンネルに何色を付けても構いません）。<br>最初の色は Hoechst/DAPI＝青、AF488＝緑、AF555＝オレンジ、AF647＝赤です |
| 範囲 | `%`（ふつうはこちら）か `輝度`（下の「明るさ」を参照） |
| 下限・上限 | 明るさの調整です。**下限を上げると背景が暗く締まります**。**上限を下げると明るくなります**。数値を直接入力することもできます |
| 明るさ（スライダー） | 各チャンネルの下の段にあるバーです。**つまみを引っ張って**明るさを調整します。<br>左のつまみ＝下限（右へ動かすと背景が締まる）、右のつまみ＝上限（左へ動かすと明るくなる）です。<br>動かすと、下限・上限の数値とプレビューもすぐ変わります。暗い側ほど細かく動くようになっています |
| ガンマ | 中間調の明るさです（ZEN の Gamma と同じ考え方）。**1.00 がそのまま**です。<br>1 未満（例 0.70）にすると中間調が明るくなり、暗い構造が見えやすくなります。1 より大きく（例 1.50）すると中間調が暗くなり、背景が締まります。<br>黒（下限）と白（上限）の位置は変わりません。数値の欄を右クリックすると 1.00 に戻ります |
| → 輝度 | 実際に黒〜白に割り当てている元の輝度値です（参考） |
| 自動 | 明るさを既定値（0.1 % 〜 99.8 %）に戻します |

### ZEN と同じ見た目から始める
.czi には、ZEN で最後に表示したときの **色・黒（下限）・白（上限）・ガンマ** がチャンネルごとに保存されています。
- 「**開いたときは ZEN の表示設定から始める**」に印が付いていると（最初から付いています）、.czi を開くたびにこの設定で表示します。
  色の欄には「ZEN #0076FF」のように ZEN の色がそのまま入り、範囲は「輝度」になり、合成方法は ZEN と同じ「加算」になります。
- 自分で調整したあとに ZEN の見た目へ戻したいときは、上の「**ZEN の表示に合わせる**」を押します。抗体名・ラベル・枠はそのままです。
- 印を外すと、これまでどおりの自動調整（0.1〜99.8 %・純色）で開きます。

注意：
- ZEN は「初期値のままの項目」を保存しません。黒が保存されていなければ 0、白が保存されていなければ全範囲（16 bit なら 65535）として扱います。
  ZEN で白を一度も調整していないチャンネルはとても暗く見えることがあるので、そのときは画面に注意が出ます。上限を下げてください。
- ZEN の画面と細部まで同じにはならないことがあります（ZEN 側の画面表示の処理までは分からないため）。気になるときは同じ画像を ZEN と見比べてください。

**明るさのコツ**
- 背景がうっすら色づくとき（信号の弱いチャンネルでよく起きます）は、スライダーの左のつまみを右へ引っ張るか、下限を 0.1 → 20〜50 % くらいまで上げてみてください。
- 同じ条件で撮った画像どうしを**同じ明るさで**比べたいときは、範囲を `輝度` にしてください。
  今の見た目のまま数値が固定されます。その設定を「設定を保存」しておけば、他のファイルにも同じ数値を使えます。

### ③ ラベル・タイトル・スケールバー
- 「左の縦書きラベル」に文字を入力します（例: ACh DIV 26）。
- スケールバーの長さは µm で指定します。右側に、何ピクセルになったかが出ます。
- **赤をマゼンタにする**：赤緑の区別が難しい人向けです。画像とタイトルの赤が、まとめてマゼンタになります。
- 文字が小さい・大きいときは、「文字・枠の大きさ」で調整します。

### ④ 保存
1. 「書き出すもの」で「合成パネル」「単色パネル」に印を付けます。両方でも構いません。
2. 「形式」を選びます。
   - **PNG 画像**：これまでどおりの 1 枚の画像です。
   - **PowerPoint（.pptx）**：1 パネルが 1 スライドになります（下の「PowerPoint で書き出すと」を参照）。
   - **両方**：PNG と、同じ名前の .pptx を一緒に保存します。
3. 「保存…」を押します（`Ctrl+S`）。
   - ファイル名は「.czi の名前_ラベル」で自動的に入ります。単色パネルの PNG は「…_抗体名.png」です。
   - 既定の保存先は `ドキュメント`（`C:\Users\yossy\OneDrive\Documents\`）です。前回の保存先は次回も覚えています。
   - 同じ名前のファイルがあると「上書きする／既存は残して他だけ保存／キャンセル」を聞かれます。
- 「拡大」：画像を 2〜4 倍に引き伸ばします。画素の値は変わらず、スケールバーも正しく伸びます。
- 「解像度の記録」：PNG に書き込む dpi です（既定 300）。画面の下に、その dpi で印刷したときの幅（mm）が出ます。

### PowerPoint で書き出すと
1 スライドに、次の **7 つのオブジェクト**が別々に入ります（グループ化はしていません）。
PowerPoint の「選択ウィンドウ」（ホーム → 選択 → オブジェクトの選択と表示）に、この名前で並びます。

| 名前 | 中身 | PowerPoint でできること |
|---|---|---|
| 画像 | 合成画像（スケールバーは入っていません） | 移動・拡大縮小（縦横比は固定） |
| タイトル枠 | 上の四角形（枠線だけ・塗りなし） | 線の太さ・色の変更 |
| ラベル枠 | 左の四角形（枠線だけ・塗りなし） | 同上 |
| タイトル文字 | 抗体名のテキストボックス（抗体ごとに色付き） | 文字の打ち直し、色やフォントの変更 |
| ラベル文字 | 縦書きのテキストボックス | 文字の打ち直し |
| スケールバー | 白い四角形（枠線なし） | 移動・色の変更 |
| スケールバー文字 | 「50 µm」のテキストボックス（白） | 文字の打ち直し・移動 |

**スケールバーの長さについて（大事）**
- スケールバーの長さは、µm ÷ µm/px で計算した正確な長さです（例：50 µm は 160.28 画素ぶん）。
  PNG は画素単位でしか描けないので 160 画素（49.91 µm）に丸めますが、PowerPoint では丸めずにちょうど 50.00 µm にしています。
- バーは画像とは別のオブジェクトなので、**画像だけを拡大・縮小するとバーの長さが合わなくなります**。
  大きさを変えるときは、画像とスケールバー（とスケールバー文字）を一緒に選んでから拡大・縮小してください。
  Ctrl を押しながらクリックで複数選べます。まとめて扱いたいときは、選んだ状態で右クリック →「グループ化」も便利です。
- 「50 µm」の文字を「50 μm」などに打ち直しても、バーの長さは変わりません。長さを変えたいときは、アプリでスケールバーの µm を変えて書き出し直してください。

- 見た目と位置は PNG と同じです。スライド（16:9）の中央に収まる大きさで置きます。
- フォントは Arial Bold です（日本語の部分は游ゴシック）。
- スライドのノートに、元のファイル名・µm/px・スケールバーの長さ・各チャンネルの明るさの設定を書いておきます（あとで条件を確かめるため）。
- 「全シーンを一括保存」や「複数の .czi に同じ体裁で一括保存」で PowerPoint を選ぶと、**全部を 1 つの .pptx にまとめます**（1 パネル＝1 スライド）。
- 「タイトル枠」「ラベル枠」の表示を切ってある場合は、その枠と文字は作りません。

## 4. 同じ体裁を使い回す

### 設定を保存／読込
- 「設定を保存…」：今の色・明るさ・枠・スケールバーなどを `.json` に保存します。
- 「設定を読込…」：その `.json` を読み込みます（`Ctrl+L`）。
  **このツールで保存した PNG を選んでも、その PNG を作ったときの設定が戻ります**（PNG の中に記録してあります）。

別の `.czi` に設定を当てると、色・ON/OFF・明るさ・並び順・体裁は保存したとおりになります。
**抗体名と左ラベルは、新しいファイル名から推測できたもの**が優先されます。
これで、PAX6 のファイルに前の「TBR1」という名前が残るのを防いでいます。推測できなかった名前は、保存したものを使います。
チャンネルは「何番目か」ではなく「DAPI / 488 / 555 / 647」で対応付けます。ファイルごとにチャンネルの順番が違っても大丈夫です。

`.czi` を開いた状態で別の `.czi` を開いたときも、同じルールで体裁が引き継がれます。

### 複数ファイルを一括で
「複数の .czi に同じ体裁で一括保存…」を押して、ファイルをまとめて選びます（`Ctrl` か `Shift` を押しながらクリック）。
選んだ全部が、今の体裁で保存されます。

## 5. pptx データまとめ（Nega ＋ 実験画像 → 7 パネル × 2 枚）

Nega（陰性対照・noAb）と実験画像（本染色）の 2 つの .czi から、
単染色 3 枚（AF488 / AF555 / AF647）＋マージ 4 枚の 7 パネルを、参考と同じ様式の PowerPoint 2 枚にまとめます。

| | 1 枚目 | 2 枚目 |
|---|---|---|
| White の決め方 | 実験画像から | Nega から |
| 左下の枠 | 実験画像における White | Nega における White |
| 日付の下 | （なし） | 「Nega 基準」と Nega のファイル名 |

どちらも表示するのは実験画像で、Black = 0、ガンマ 1.0 です。
色は AF488 = 緑、AF555 = 青、AF647 = 赤。透過光は使いません。

**「作るもの」の切り替え**（画面の上のほう。選んだ状態は次回も覚えています）
- **2 枚目（White を Nega から決めたスライド）も作る**：外すと 1 枚目だけを作ります。このときは Nega の .czi は不要です
  （選んでおけば、チャンネル構成などの整合チェックだけ行います）。
- **DAPI（Hoechst）のパネルを入れる**：入れると下段を上段と同じ 4 列にそろえ、右端に DAPI の単染色を入れます。
  DAPI は AF555 の青と混ざらないよう **白黒** で表示し、マージには入れません。
  左下の White の枠にも DAPI の値が入ります（枠は下段 1 列目に掛からないよう少し小さくなります）。

**使い方**
1. メイン画面の「pptx データまとめ（Nega ＋ 実験画像 → 7 パネル）…」を押します（`Ctrl+M`）。
2. 「参照…」で Nega と実験画像の .czi を選びます。メイン画面で開いている .czi は実験画像として最初から入ります。
3. 抗体名（タイトルに出る名前）を確かめます。ファイル名から自動で入ります。
4. 必要なら White（%）・重なりの合成・コメントを変え、プレビュー（1 枚目／2 枚目）で確かめます。
5. 「pptx を保存…」を押します。ファイル名は「実験画像の名前_まとめ_日付.pptx」で自動的に入ります。

**White の決め方**
- その画像の各チャンネルで、「White より明るい画素」が全体の **White（%）** になる整数の値です。
  ZEN の Best Fit の White(%) と同じ考え方で、**既定は 0.25 %** です（ZEN で使っている設定）。
- 実験画像で ZEN の Best Fit（0.25 %）と比べると、37272 / 3819 / 9763 に対してアプリは 37230 / 3747 / 9582 で、差は 2 % 以内です。
- 1 枚目と 2 枚目には同じ % を使います。
- 完全に白飛びした画素だけで目標の % を超えてしまうチャンネルには、画面に「飽和あり（○枚目）」と出ます。

チャンネルは並び順ではなく、メタデータの色素名（AF488 / AF555 / AF647）で対応付けます。
Nega と実験画像でチャンネル構成・ビット深度・画像サイズ・µm/px が違うときは、画面に警告が出ます。

## 6. マルチシーン（複数 Position）の .czi

シーンが 2 つ以上あるファイルを開くと、「シーン（Position）」の欄が出ます。
- 番号を変えると、そのシーンがプレビューに出ます。
- 「全シーンを一括保存」で、全部のシーンを今の体裁で保存します。ファイル名には `_S0`、`_S1` … が付きます。

## 7. コマンドで使う場合（任意）

```bat
py czi_figure_core.py "xxx.czi" --list
py czi_figure_core.py "xxx.czi" --label "Glu DIV 30" --channels "DAPI:Hoechst:blue,AF488:MAP2:green,AF647:TBR1:red" --single --save-config 体裁.json
py czi_figure_core.py "a.czi" "b.czi" "c.czi" --config 体裁.json --out-dir "C:\Users\yossy\OneDrive\Documents\figs"
py czi_figure_core.py "multi.czi" --all-scenes --config 体裁.json
py czi_figure_core.py "a.czi" "b.czi" --config 体裁.json --format pptx --pptx まとめ.pptx
py czi_figure_core.py "a.czi" --zen --label "ACh day26"          （ZEN の表示設定で描く）
py czi_summary.py --nega "Nega.czi" --exp "実験.czi"                （pptx データまとめ。--white-percent で % を変更）
py czi_summary.py --exp "実験.czi" --dapi --no-nega-slide           （DAPI あり・1 枚目だけ）
```
既存ファイルは上書きしません。上書きしたいときは `--force` を付けてください。

## 8. 他の PC で使う（.exe 版・Python 不要）

`dist\CZI_Figure_Windows.zip`（約 170 MB）を渡すだけで、Python が入っていない Windows PC でも動きます。

1. zip を右クリック → 「すべて展開」します（**zip のまま中の exe を開いても動きません**）。
2. 展開した `CZI_Figure` フォルダの中の `CZI_Figure.exe` をダブルクリックします。
   - フォルダは丸ごと使ってください（中の `_internal` フォルダも必要です）。
3. 初回は「Windows によって PC が保護されました」と出ることがあります。
   「詳細情報」→「実行」で起動します（電子署名が無いアプリに必ず出る確認です）。

- 動くのは Windows 10 / 11（64 bit）だけです。Mac では動きません。
- エラーが起きると、内容が `%LOCALAPPDATA%\czi_figure\error.log` に残ります。
- 中身はこのフォルダの .py と同じです（出力が 1 ピクセルも変わらないことを確かめてあります）。

### .exe を作り直す（.py を直したとき）
`packaging\build_exe.bat` で作り直せます。詳しい手順はファイルの先頭に書いてあります。
余計なパッケージが入らないよう、専用の環境（venv）で作るのがおすすめです。

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| 黒い画面がすぐ閉じる | `launch_gui.bat` を使って起動すると、エラーの文章が残ります。その画面を写真に撮って相談してください |
| `Python was not found; run without arguments to install from the Microsoft Store…` | `launch_gui.bat` を最新版にしてください（本物の Python を自分で探すようになっています）。<br>`python` と打ったときに、Microsoft Store の「ダミーの python」が先に見つかってしまうのが原因です。<br>コマンドで直接動かすときは、`python` の代わりに `py` を使ってください（例: `py czi_figure_core.py …`）。 |
| `Python was not found. Install Python…`（bat が出す英語のメッセージ） | Python 自体が見つかりません。conda 環境を使うなら、bat の `rem call conda activate cellcount` の `rem ` を消してください |
| `PowerPoint 書き出しには python-pptx が必要です` | `py -m pip install python-pptx` を 1 回実行してください（PNG だけなら不要です） |
| `Some packages are missing` | 画面に出たコマンド（`… -m pip install -r requirements.txt`）を 1 回実行してから、もう一度起動してください |
| `run_analysis_9th.py が見つかりません` | 4 つのファイルを同じフォルダに置いてください |
| `.czi を読むためのライブラリがありません` | `pip install czifile` |
| `No module named 'qtpy'` / `PyQt6` | `pip install qtpy PyQt6`（napari が入っている環境なら不要のはず） |
| スケールバーが出ない | その .czi に µm/px が記録されていません（ファイル名の下に「µm/px 不明」と出ます） |
| 画像が真っ暗・真っ白 | そのチャンネルの「自動」を押してから、下限・上限を少しずつ動かしてください |
| 背景が色づいて汚い | 下限を上げてください（例 0.1 → 30 %） |
| 日本語のラベルが横倒し | 仕様です。横書きの文字列を 90° 回して置いています |
| 画面の文字が □ になる | Windows の「游ゴシック」が必要です（通常は入っています） |
